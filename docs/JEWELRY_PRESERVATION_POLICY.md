# JEWELRY PRESERVATION POLICY (LOCKED)

User-locked, highest priority, applies to EVERY catalog and EVERY image (studio + lifestyle).
Scope: how the jewellery itself must be preserved. (Background = BACKGROUND_RULES; Logo = LOGO_RULES;
Pipeline = IMAGE_GENERATION_RULES; per-ring geometry = each catalog's SOURCE_SPEC.)

## Master rule (highest priority)
- Jewellery redesign/redrawing is STRICTLY PROHIBITED. NO AI in the jewellery design — use ONLY the source image.
- The DIAMOND SHAPE stays exactly as the source — never turn it into another shape (hexagon stays hexagon, shield stays shield, baguette stays baguette).
- Every diamond's SIZE, CUT, FACET, SHAPE is D2D pixel-perfect to the source — no compromise. Size/shape/design come ONLY from the source.
- Applies to EVERY image including lifestyle/on-hand. Same rule, no exception.

## Band never changes (permanent — all rings, all catalogs)
- NEVER change the band (shank) in any ring. It must stay EXACTLY as the source in every image.
- Preserve exactly: band profile, thickness, width, taper, curve/shape, metal, finish, and any engraving/pavé/milgrain on the band.
- Do NOT restyle, thicken, thin, round, flatten, split, add pavé, add engraving, remove detail, or alter the band in any way. The band is part of the locked source design.

## Physical & logical correctness (permanent, all catalogs)
- The ring must be physically real and logically possible. A single ring has EXACTLY the band structure of the source — normally ONE continuous band (shank).
- NEVER generate 2/3/multiple bands, loops, rails, shanks, split rails, floating loops, duplicated or ghost bands — unless the source genuinely has them.
- The band is one closed continuous loop with correct thickness/profile; stones sit in that single band. Nothing floating, merged, doubled, or impossible.
- The ring is worn on ONE finger only — never spanning/resting across two fingers.
- Validate before output: count the bands — must equal the source (usually 1); ring on one finger only. Reject extra/duplicate bands, two-finger placement, impossible geometry, floating parts.

## Stone layout — orientation, spacing, count (permanent, all catalogs)
- Preserve ORIENTATION exactly: source east-west marquise/oval/pear (long axis along the band) stays east-west — never rotate vertical/tilted/radial. Match the exact tilt/direction of every stone.
- Preserve SPACING & rhythm: evenly-spaced-with-gaps + shared/common prongs stays that way — never pack, cluster, cram, bunch. If stones touch in source, keep them touching.
- Preserve exact stone COUNT — never add/drop stones to fill the arc.
- Preserve the setting style between stones (shared prong / bead / bar) exactly.
- Study the source arrangement (orientation + spacing + count + prong style) BEFORE generating.

## Read all angles first (hard gate)
- Before generating: study ALL source angles and confirm you have them.
- If a required angle is not covered by the source, do NOT start generation. Never generate an angle with no source view.

## Realistic ring scale on hand (permanent, all catalogs)
- Every on-hand/lifestyle image renders the ring at TRUE real-life size, proportionate to a real hand.
- The centre stone sits WITHIN the finger's width — never wider than the finger, never oversized/cocktail-huge.
- Match the source's real proportions; an elongated stone spans ALONG the finger but must not overhang the sides.
- Validate before output: stone width <= finger width, natural proportion. Reject oversized-on-hand.

## Natural materials (100% real look)
- Diamonds, gold, silver, all metals look 100% natural/real — like a genuine photograph. Real brilliance/facets, authentic metal reflections/texture.
- NOTHING artificial: no plastic/CZ/glass look, no AI-metal, no over-glossy/CGI. Natural light + realistic material response. Reject artificial-looking.

## Priority
- JEWELLERY IS THE HERO — always the clear focus of every image.

## Source lock
- Use the source CAD as a structure-locked image reference. NEVER redraw/generate the jewellery from text or category priors.
- Do not change the jewellery even 0.000000000001%. Only the camera angle may change.
- In lifestyle shots, transfer the EXACT source ring onto the finger (image-to-image / inpaint the ring region); never let the model draw its own diamond.

## Diamonds
- Match every stone's exact shape/cut/facets/count/size/placement to source. Never substitute, guess, or "beautify."
- Do not add/remove any stone, halo, or pave that is/isn't in the source.
- Facets/angles sharp and clearly visible. No blur/melt/round/merge.

## Prongs / setting
- Match prong count/shape/style/thickness/position exactly. No added/split/doubled/restyled prongs.
- Lock gallery, basket, bridge, cathedral, band, engraving/filigree to source. Do not add/remove decorative metalwork.

## Head alignment
- The head (stone + setting) sits CENTERED and SQUARE on the band from EVERY angle. Shoulders meet the basket symmetrically; head not tilted/offset.

## Hexagon side-angle rule
- For elongated-hexagon centre stones, do NOT use the dead-flat pure side profile (it foreshortens the stone, hiding the pointed top/bottom so it reads as a flat-top emerald cut — wrong).
- Use a 3/4 side angle (~30-45 deg off pure profile) so the POINTED top/bottom stay visible while still showing the band side.

## Check (before delivery; validate BEFORE generation)
Compare with source. Reject on ANY mismatch: wrong diamond shape/size/cut/facets; changed band; wrong stone
orientation/spacing/count; extra/duplicate bands or impossible geometry; two-finger placement; changed design;
added/removed stones/halo/metalwork; wrong prongs; off-center head; oversized/wrong scale on hand; artificial/fake material look.
