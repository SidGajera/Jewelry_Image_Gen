# JEWELRY PRESERVATION POLICY (LOCKED)

Scope: how the jewellery itself must be preserved. General rules for ALL catalogs. (Background = BACKGROUND_RULES;
Logo = LOGO_RULES; Pipeline = IMAGE_GENERATION_RULES; per-ring geometry = each catalog's SOURCE_SPEC.) User-locked.

## #0 READ THE SOURCE FIRST (HIGHEST PRIORITY — before anything, no compromise)
- Before ANY generation, READ and ANALYZE the source image completely and perfectly — every provided angle, every stone (shape/count/orientation/spacing/type), the band, prongs, setting, proportions. Build a precise model of the real design.
- Redesign or redrawing the jewellery is STRICTLY BANNED. Never invent, guess, or "fill in" the design.
- If you do NOT have a source view for a required angle, do NOT generate/redraw it. Reply plainly: **"I don't have the source angle to generate this image."** Never violate the policy by redrawing.
- Only generate angles you actually have in the source. No fabricated angles.

## #0.1 EXACT DETAIL MATCH — count & analyze EVERY detail (D2D pixel-perfect)
- Every piece must match the source EXACTLY on every single detail, front side AND back side. Miss nothing.
- COUNT and match precisely: number of diamonds, number of prongs (per stone and total), number of settings, side stones, accent stones, pavé stones. Every count must equal the source — front and back.
- MATCH precisely for every stone: shape, cut, size, length/width ratio, orientation/angle, facet pattern, position/spacing.
- MATCH precisely: prong style/shape/count/position, setting type, gallery, basket, bridge, cathedral, band profile, engraving, milgrain — front and back.
- Study every minor detail deliberately before generating; never skim or assume. Final design must be D2D pixel-perfect.
- Validate before output by COUNTING: diamonds, prongs, settings, side/accent stones — all must equal source, front and back.

## Master rule (highest priority)
- Jewellery redesign/redrawing is STRICTLY PROHIBITED. NO AI in the jewellery design — use ONLY the source image.
- The DIAMOND SHAPE stays exactly as the source — never turn it into another shape (hexagon stays hexagon, shield stays shield, baguette stays baguette).
- Every diamond's SIZE, CUT, FACET, SHAPE is D2D pixel-perfect to the source. Size/shape/design come ONLY from the source.
- Applies to EVERY image including lifestyle/on-hand. No exception.

## Band never changes (permanent — all rings, all catalogs)
- NEVER change the band (shank). It stays EXACTLY as the source in every image.
- Preserve exactly: band profile, thickness, width, taper, curve/shape, metal, finish, and any engraving/pavé/milgrain on the band.
- Do NOT restyle, thicken, thin, round, flatten, split, add pavé, add engraving, remove detail, or alter the band in any way.

## Physical & logical correctness (permanent, all catalogs)
- The ring must be physically real and logically possible. A single ring has EXACTLY the source's band structure — normally ONE continuous band (shank).
- NEVER generate 2/3/multiple bands, loops, rails, shanks, split rails, floating loops, duplicated/ghost bands — unless the source genuinely has them.
- The ring is worn on ONE finger only — never spanning/resting across two fingers.
- Validate before output: count the bands (must equal source, usually 1); ring on one finger only. Reject extra/duplicate bands, two-finger placement, impossible geometry, floating parts.

## Stone layout — orientation, spacing, count (permanent, all catalogs)
- Preserve each stone's ORIENTATION exactly: marquise/oval/pear set EAST-WEST stay east-west — never rotate vertical/tilted/radial.
- Preserve SPACING & rhythm: keep gaps, shared/common prongs, and any round accent stones between marquises exactly — never pack, cluster, or bunch. If stones touch in source, keep them touching.
- Preserve exact stone COUNT and stone TYPES — never add, drop, or swap.
- Preserve the setting style between stones (shared prong / bead / bar) exactly.

## Read all angles first (hard gate)
- Study ALL angles of the source and confirm you have them. If you cannot cover a required angle, do NOT start — say "I don't have the source angle." Never generate an angle you do not have a source view for.

## Realistic ring scale on hand (permanent — all catalogs)
- Ring at TRUE real-life size, proportionate to a real hand. Centre stone within the finger's width — never wider, never oversized.
- Validate before output: stone width ≤ finger width. Reject oversized-on-hand.

## Natural materials (100% real look)
- Diamonds/gold/silver/metals look 100% natural, real, original — like a genuine photograph. Real brilliance/facets, authentic reflections/texture.
- Nothing artificial: no plastic/CZ/glass/CGI look. Natural light + realistic material response. Reject artificial-looking.

## Priority
- JEWELLERY IS THE HERO — always the clear focus of every image.

## Source lock
- Use the source CAD as a structure-locked image reference. NEVER redraw/generate the jewellery from text or category priors.
- Do not change the jewellery even 0.000000000001%. Only the camera angle may change.
- In lifestyle shots, transfer the EXACT source ring onto the finger (i2i / inpaint the ring region); never let the model draw its own diamond.

## Prongs / setting
- Match prong count/shape/style/thickness/position exactly. No added/split/doubled/restyled prongs.
- Lock gallery, basket, bridge, cathedral, band, engraving/filigree to source. Do not add/remove decorative metalwork.

## Head alignment
- The head sits CENTERED and SQUARE on the band from EVERY angle. Shoulders meet the basket symmetrically; head not tilted/offset.

## Hexagon side-angle rule
- For elongated-hexagon centres, avoid the dead-flat pure side profile (reads as flat-top emerald). Use a 3/4 side (~30–45°) so the pointed top/bottom stay visible.

## Check (before delivery; validate BEFORE generation)
Compare with source. Reject on ANY mismatch: wrong diamond shape/size/cut/facets; wrong COUNT of diamonds/prongs/settings
(front or back); changed band; wrong stone orientation/spacing/type; extra/duplicate bands or impossible geometry;
two-finger placement; changed design; added/removed metalwork; off-center head; oversized scale; artificial look.
If you lack the source angle needed, STOP and say "I don't have the source angle to generate this image" — never redraw.
